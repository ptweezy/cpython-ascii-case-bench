# Which variants compile to the same machine code

`tests/same_code.sh` (WSL2 on the Ryzen 7 9800X3D; gcc 13.3, clang 18.1.3): each variant's helpers copied verbatim from its patched `Objects/bytes_methods.c` (`oldcc/make_test.py`), compiled at -O2, -O3 and -Os, and the disassembly of `ascii_case_words` compared. Cross targets use clang `--target`.

- `varB` = `varT` (16-byte GNU vector) on x86-64 without AVX2 only: with AVX2, AVX-512 or on aarch64 `varB` uses 32 bytes.
- `varB` = `varN` on x86-64, with and without AVX2 and AVX-512; not on aarch64 (`varN` uses 16 bytes there).
- `varB` = `varO` (32-byte vector) with AVX2, with AVX-512 and on aarch64; not on x86-64 without AVX2, where `varB` uses 16 bytes.
- `varB` = `varB5` everywhere except with AVX-512, where `varB5` uses 64 bytes.
- `varB` = the PR on 32-bit x86, riscv64, ppc64le and s390x: there `varB` is the PR's word loop, unchanged, where `varT`, `varN` and `varO` have `varR`'s plain-C block. For 32-bit Windows, MSVC's function for `varB` has the PR's size and SIMD count (`local/msvc_simd.md`).

Every row matches what the source says it should.
